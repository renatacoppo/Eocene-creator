External tools
==============

This page will describe the external tools reached by the workflow: the NEMO DOMAINcfg tool
used to build the PALEORCA2 domain, the OASIS library, the backends that run them
(``atos``, ``local``, ``fake``) and how to use them on ECMWF Atos. Today the Eocene domain is
built on Atos and passed to the workflow through the ``domain`` key (see :doc:`configuration`).
